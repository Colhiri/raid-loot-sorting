# Raid Loot Sorting

Мод для SPT 4.0.13 и Tarkov 0.16.9.40087. Для выделения нескольких предметов используется [UI Fixes 5.3.9](https://github.com/tyfon7/UIFixes/releases/tag/v5.3.9).

Ветка `support/4.0` поддерживает SPT 4.0.13. Для SPT 4.1.6 используется ветка `main`.

## Выгрузка после рейда

Зайди в рейд за ЧВК. Мод сам запомнит фактическую экипировку и её содержимое при входе. После рейда открой «Персонаж → Вещи» и нажми **Выгрузить весь лут** справа от «Сорт. стол» над схроном. Снимок хранится отдельно для каждого профиля. Именованная сборка в игре для этого не нужна.

Если рейд начался до установки мода или снимок потерялся, кнопка покажет сообщение и оставит экипировку на персонаже. Мод запомнит комплект при следующем входе в рейд за ЧВК. Встроенные резервные копии SPT лежат в `SPT/user/profiles/backups` при настройках по умолчанию. По ним можно сверить вещи вручную, если известна нужная копия.

- Предметы из дорейдовой экипировки остаются на персонаже. Подобранное оружие переносится целиком. Новые съёмные модули на оружии из своей сборки выгружаются отдельно.
- В ящики для хлама отправляются только подходящие предметы с отметкой «Найдено в рейде». Когда в ящиках тесно, остаток идёт ниже занятых строк схрона с отступом в одну строку. После него остаётся ещё одна пустая строка, затем выкладывается остальной лут. Если ящики приняли весь хлам с отметкой, достаточно одного отступа после основного схрона.
- Вещи выгружаются по категориям и типам. Как только в нижней части схрона нет места под очередной предмет, выгрузка останавливается. Остаток остаётся на персонаже.

## Распределение в схроне

Щёлкни правой кнопкой по предмету в схроне или внутри открытого контейнера и выбери **Распределить по контейнерам**. Для группы используй выделение UI Fixes. У выбранного заполненного рюкзака, разгрузки или ящика команда распределяет содержимое сеток. Пустой контейнер обрабатывается как отдельный предмет.

Приоритет у подходящих профильных ящиков. Инъекторы идут в инъекторницу или медицинский ящик, патроны в патронный, гранаты в гранатный. Для хлама сначала проверяется ящик для хлама, затем кейсы для вещей. Если подходящие места заполнены, предмет остаётся на прежнем месте.

## Установка

Распакуй архив в корень SPT. DLL должна находиться в `BepInEx/plugins/RaidLootSorting/RaidLootSorting.dll`. При удалении мода можно также удалить снимки из `BepInEx/config/RaidLootSorting`.

## Сборка

```powershell
dotnet build RaidLootSorting.csproj -c Release -p:SptRoot=D:/SPT
```
