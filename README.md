# Raid Loot Sorting

Мод для SPT 4.0.13 и Tarkov 0.16.9.40087. Для выделения нескольких предметов используется [UI Fixes 5.3.9](https://github.com/tyfon7/UIFixes/releases/tag/v5.3.9).

Ветка `support/4.0` поддерживает SPT 4.0.13. Для SPT 4.1.6 используется ветка `main`.

## Выгрузка после рейда

Открой «Персонаж → Вещи» и нажми кнопку со стрелкой над закреплением и блокировкой сбоку от схрона. Мод запоминает фактическую экипировку при входе в рейд за ЧВК. Снимки хранятся отдельно по профилям.

- С выделением на ЧВК выгружаются только выделенные предметы. У выделенных рюкзаков, разгрузок и других контейнеров выгружается содержимое сеток, а сами контейнеры остаются на персонаже.
- Без выделения и со снимком выгружается лут сверх дорейдовой экипировки. Подобранное оружие переносится целиком. Новые съёмные модули на оружии из снимка выгружаются отдельно.
- Без выделения и без снимка выгружается вся съёмная экипировка ЧВК, включая рюкзак и разгрузку после их опустошения. Закреплённые, заблокированные, квестовые и несъёмные предметы остаются на месте.
- В ящики для хлама отправляются только подходящие предметы с отметкой «Найдено в рейде». Для каждого предмета проверяются все подходящие ящики. Остаток идёт в свободную зону ниже основного схрона, с отступом в одну строку. После него остаётся ещё одна пустая строка, затем выкладывается остальной лут. Если ящики приняли весь хлам с отметкой, достаточно одного отступа после основного схрона. Отдельные предметы в нижних строках занимают свои клетки, и свободные строки выше них остаются доступны для выгрузки.
- Вещи выгружаются по категориям и типам. Как только в нижней части схрона нет места под очередной предмет, выгрузка останавливается. Остаток остаётся на персонаже.

## Распределение в схроне

Щёлкни правой кнопкой по предмету в схроне или внутри открытого контейнера и выбери **Распределить по контейнерам**. Для группы используй выделение UI Fixes. У выбранного заполненного рюкзака, разгрузки или ящика команда распределяет содержимое сеток. Пустой контейнер обрабатывается как отдельный предмет.

Приоритет у подходящих профильных ящиков. Инъекторы идут в инъекторницу или медицинский ящик, патроны в патронный, гранаты в гранатный. Для хлама сначала проверяется ящик для хлама, затем кейсы для вещей. Если предмет не помещается в один ящик, мод проверяет остальные подходящие сетки и контейнеры. Когда ни один контейнер не принимает предмет, мод пробует свободные клетки самого схрона. Предмет остаётся на месте, если он уже лежит в самом схроне или если подходящих клеток нигде нет.

## Установка

Распакуй архив в корень SPT. DLL должна находиться в `BepInEx/plugins/RaidLootSorting/RaidLootSorting.dll`. При удалении мода можно также удалить снимки из `BepInEx/config/RaidLootSorting`.

## Сборка

```powershell
dotnet build RaidLootSorting.csproj -c Release -p:SptRoot=D:/SPT
```
