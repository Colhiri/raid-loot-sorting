# Raid Loot Sorting

[English](README.md)

Мод для SPT выгружает рейдовый лут с ЧВК и распределяет выбранные предметы по контейнерам в схроне. Подсказка кнопки, контекстное меню и уведомления используют русский язык в русском клиенте и английский в остальных локализациях.

## Совместимость

| SPT | Версия мода | UI Fixes | Ветка исходников |
| --- | --- | --- | --- |
| 4.1.6 | 1.2.2 | [6.0.4](https://github.com/tyfon7/UIFixes/releases/tag/v6.0.4) | `main` |
| 4.0.13 | 1.0.4 | [5.3.9](https://github.com/tyfon7/UIFixes/releases/tag/v5.3.9) | `support/4.0` |

Закройте игру, установите UI Fixes для своей версии SPT и распакуйте подходящий [архив релиза](https://github.com/Colhiri/raid-loot-sorting/releases) рядом с `EscapeFromTarkov.exe`. DLL мода будет лежать в `BepInEx/plugins/RaidLootSorting/RaidLootSorting.dll`.

## Четыре сценария

| Ситуация | Что произойдёт |
| --- | --- |
| **На ЧВК есть снимок дорейдовой сборки** | Откройте **Персонаж → Вещи** и нажмите кнопку со стрелкой над закреплением и блокировкой сбоку от схрона. Снаряжение из снимка остаётся на ЧВК. Мод выгружает подобранный лут, прибавку к исходным стакам и новые съёмные модули. Подобранное оружие переносится со своим обвесом и патронами. |
| **Снимка сборки нет** | Та же кнопка выгружает съёмное снаряжение, пока хватает места. Рюкзак и разгрузка переносятся после опустошения. Такой режим пригодится при первом использовании или после рейда, начатого до установки мода. |
| **На ЧВК выделены предметы** | Выделите предметы через UI Fixes и нажмите кнопку со стрелкой. Выделение имеет приоритет над снимком. У выделенного рюкзака, разгрузки или ящика выгружается содержимое сеток, а сам контейнер остаётся на ЧВК. Другие выделенные вещи переносятся целиком, если игра разрешает перенос. |
| **В схроне выделены предметы** | Нажмите ПКМ по одному из выделенных предметов в схроне или открытом контейнере и выберите **Распределить по контейнерам**. Команда работает и для одного предмета. Из выбранного заполненного контейнера распределяется содержимое сеток. Пустой контейнер обрабатывается как отдельный предмет. |

При входе в локальный рейд за ЧВК мод записывает ID предметов и размеры стаков. Для каждого профиля хранится снимок фактической экипировки, с которой ЧВК вошёл в последний такой рейд. Выгрузка начинается по кнопке в схроне. Закреплённые, заблокированные, квестовые и несъёмные предметы остаются на месте. Съёмное содержимое защищённого контейнера можно выгрузить.

С настройками UI Fixes по умолчанию отдельные предметы выделяются через Shift + ЛКМ. Чтобы выделить группу рамкой, потяните её от пустой клетки, удерживая ЛКМ.

## Где появляется лут с ЧВК

1. Мод сортирует выгружаемые вещи по категориям и типам. Подходящий хлам с отметкой **«Найдено в рейде»** идёт в ящики для хлама. Для каждого предмета мод проверяет доступные ящики и при необходимости поворачивает предмет.
2. Хлам с отметкой, который не поместился в ящики, появляется в свободной зоне ниже основного схрона после одной пустой строки. Через ещё одну пустую строку выкладывается остальной лут. Если весь подходящий хлам ушёл в ящики, перед остальным лутом будет один отступ. В пустом схроне выгрузка начинается с первой строки.
3. Предметы в нижних строках продолжают занимать свои клетки, а свободное место выше них можно использовать. Когда в зоне выгрузки не помещается очередной предмет, мод останавливается. Оставшиеся вещи остаются на ЧВК.

## Как выбираются контейнеры в схроне

Мод проверяет игровые фильтры каждого контейнера и фактическое наличие свободных клеток. Профильные ящики имеют преимущество. При равном приоритете сначала проверяются контейнеры, где больше таких же предметов, затем контейнеры с предметами той же категории.

| Предмет | Приоритет |
| --- | --- |
| Инъекторы | Инъекторница, затем медицинский ящик |
| Медицина | Медицинский ящик |
| Гранаты | Гранатный ящик |
| Патроны и магазины | Патронный ящик или кейс для магазинов по типу предмета |
| Оружие и модули | Оружейные кейсы |
| Еда и напитки | Контейнер для еды |
| Хлам | Ящик для хлама, затем совместимые кейсы для вещей |
| Ключи, валюта и другие предметы | Подходящие профильные контейнеры или обычное хранилище |

Если в ящике нет места, мод проверяет следующий подходящий контейнер. Если ни один не принимает вещь из контейнера, мод пробует свободные клетки самого схрона. Предмет, который уже лежит на сетке схрона, сохраняет позицию, если подходящего контейнера нет. При отсутствии подходящих клеток вещь остаётся на прежнем месте.

Мод хранит снимки локально и отправляет переносы предметов на ваш сервер SPT через обычные игровые команды инвентаря. Внешних запросов и телеметрии нет.

## Удаление и сборка

Закройте игру и удалите папку `BepInEx/plugins/RaidLootSorting`. Чтобы удалить снимки экипировки, удалите также `BepInEx/config/RaidLootSorting`.

Для сборки используйте ветку своей версии SPT и клиентские DLL из установки после патча.

```powershell
dotnet build RaidLootSorting.csproj -c Release -p:SptRoot="D:/SPT"
```
